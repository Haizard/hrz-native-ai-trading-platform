Grounded reasoning

The model reasons. Rust does the math.

A language model is good at interpreting a setup and explaining it. It is not a calculator you should trust with a volume profile. So it never computes one.

  • Every number in a thesis comes from a typed tool result.
  • Structured market state is the input; a rendered chart is only a second opinion.
  • The answer cites the conditions, the timeframes and what would invalidate it.
  • The same values feed the chart overlay, the backtest and the bot.

AI analyst

It calls the tools. It never guesses the numbers.

The AI agent is not a language model looking at your chart. It is an orchestrator: it receives a structured JSON description of the market state — price, delta, CVD, POC, VAH/VAL, swings, liquidity, drawings, skills — and calls tool functions to fetch anything it does not already have.

Every number in its response is traceable to a tool call. If a tool did not return a number, the agent cannot state it.

  • Multi-timeframe ladder: 1D → 4H → 1H → 5M context built before forming a view.
  • Skills (methodology docs): your own trading rules loaded as structured context, not a long system prompt.
  • Explainability: every signal names the concept that fired, the timeframe it fired on, and the tool result that confirmed it.
  • Provider-agnostic: platform model (Kimi-K2), or connect your own OpenAI, Claude, Grok, DeepSeek or OpenRouter key.
  • Credit metering: chart analysis = 3 credits, quick answer = 1, backtest read = 5, strategy generation = 8.

Skills

Your methodology, loaded as data — not a prompt.

A Skill is a versioned Markdown document that describes a part of your trading methodology: your entry model, your session bias rules, your risk framework. Skills are retrieved contextually — the agent loads the ones relevant to the current setup, not all of them at once.

  • Versioned: Skills are immutable revisions. Change a rule, bump the version — old setups still carry the version they fired on.
  • Contextual retrieval: the agent selects Skills matching the current market condition, not a static system prompt.
  • Platform Skills included: 20 default Skills covering SMC, order-flow, sessions and risk — active the moment you sign up.
  • Community Skills: publish a Skill, install someone else's, fork it — you own the fork.

Backtesting

Replay real candles. Verify the report.

The backtester is an event-driven replay engine that walks a stored candle table the same way a live bot would walk incoming ticks. The analytics crate is the same one the chart calls — not a re-implementation written for speed that diverges on edge cases.

  • Every trade recorded: entry, exit, fill price, reason, PnL and the concept that triggered it.
  • Verify command: re-reads recorded trades against stored market data — exits non-zero on any discrepancy.
  • Parameter sweeps: test a range of stop/target multiples or lookback windows in one submission.
  • Performance report: win rate, expectancy, max drawdown, Sharpe, Sortino, Calmar — all computed in Rust.
  • AI interpretation: ask the agent to read the report and suggest improvements (5 credits).

Automation

Paper first. Then your own broker account.

Architecture

One deterministic core. Chart = backtest = bot.

The most common failure mode in retail trading tools is a backtest that uses different logic than the bot. Here it cannot happen — the analytics crate is the same binary everywhere.

⬡

Rust analytics core

Footprint, delta, CVD, VWAP, volume profile, market structure, imbalances and absorption — one shared crate. The chart, the backtester and the live bot call the same functions with the same rounding.

🔒

Sealed broker keys

AES-256-GCM encryption keyed on your user ID and the venue name. A key extracted from the database and loaded into a different account decrypts to garbage. Withdrawal-capable keys are rejected on input.

⬛

WASM-sandboxed AI code

Strategy logic generated by the AI is compiled to WASM and run inside an isolated module with no filesystem, no network, no shell access, and a strict instruction-count budget. A panic traps the module.

✓

Verifiable backtests

Every recorded trade references the exact candle it triggered on. The verify command re-reads those trades against the stored candle table and exits non-zero on any discrepancy.

Infrastructure

How the data pipeline works.

01

Exchange WebSocket

A persistent Rust WebSocket client subscribes to the exchange aggTrade and depth streams for every tracked symbol. Reconnects and deduplication are handled in the market-data crate.

02

Trade normalisation

Each incoming trade is timestamped, tagged as aggressor buy or sell, and appended to the candle builder. The buy/sell split used by the chart is exactly what arrived from the exchange.

03

Analytics crate

Completed bars pass through the shared analytics-core crate: footprint cells, bar delta, cumulative delta, VWAP, volume profile and market structure are computed once and cached.

04

Gateway WebSocket

The api-gateway fans the computed bars and order-book updates to every subscribed client over a single binary-framed WebSocket. Charts and bots share the same stream.

Common questions

Does the agent compute indicators itself?

No. It selects tools and interprets their structured results. The arithmetic lives in the shared Rust analytics crate, which is also what the chart and the backtester call.

Can I paste a TradingView Pine script?

Pine-lite follows Pine’s shape but is not source-compatible. Scripts generally need adaptation, and strategy emulator defaults differ. The validator reports what it cannot accept.

How do I know a backtest is honest?

The report records the trades it took. The verify command re-reads those trades against the stored candle table and exits non-zero on any finding.

Footprint guide · read the auction

  1. Read each row: left is sell-side aggression at the bid, right is buy-side aggression at the ask. Delta is the difference; the outlined row is that candle's point of control (POC).
  2. Read the colors: green/red shows which direction had more activity at that price; stronger shading means more activity relative to that candle's busiest row. Outlines mark diagonal imbalances; adjacent outlines form a stacked imbalance.
  3. Look for effort versus result: heavy aggression with little price progress can be consistent with absorption, but a footprint alone cannot prove who was absorbing or why.
  4. Use a sequence: first define market context, then a meaningful location (such as a value edge or prior swing), then wait for rejection and a shift in order-flow pressure. Avoid treating a single colored cell as an entry signal.

This is analysis context, not an execution signal. Plan the invalidation level before a trade. Deriv displays quote-tick pressure estimates; it does not provide traded volume-at-price or aggressor-side fills.
