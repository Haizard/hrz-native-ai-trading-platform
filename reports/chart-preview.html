The engine's own output, drawn

The scene below is not hand-drawn and not simulated: it is the JSON chart_engine.wasm returned for a request with zones: true, rendered with the same rules the shell uses. Zones sit behind the candles because a supply/demand band is a backdrop the price is read against, not a mark on top of it.

    A fresh zone is drawn solid; a mitigated one is faded, because a zone price has already traded back through is not a level any more. The band arrives with its height as h rather than as two edges to subtract — the same shape ProfileBar already had, so the shell's fill is fillRect(x, y_top, w, h).
